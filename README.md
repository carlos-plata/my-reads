# MyReads: Your Personal Book Tracker

This application provides a way to organize a personal library. You can categorize books into distinct shelves and discover new reads through a search functionality.

## Get Started in Minutes

1.  **Clone the Repository:**
    ```bash
    git clone <your-repository-url>
    ```
2.  **Install Dependencies:**
    ```bash
    cd my-reads-project
    npm install
    ```
3.  **Launch the App:**
    ```bash
    npm start
    ```
    Your browser will automatically open MyReads at `http://localhost:3000`.

## Core Features

* **Organize Your Bookshelves:** Clearly view your collection divided into "Currently Reading," "Want to Read," and "Read" shelves for easy management.
* **Effortless Shelf Management:** Quickly move books between categories using the intuitive dropdown menu associated with each book.
* **Powerful Book Search:** Discover new books by entering keywords related to titles, authors, or ISBNs. The search updates dynamically as you type.
* **Direct Library Integration:** Seamlessly add books found through search directly to your personal bookshelves with a single click.

## API Interaction

MyReads utilizes the Udacity Books API to fetch book data and persist your bookshelf organization. All API interactions are handled efficiently in the background.

## Built With

* [React](https://react.dev/) - The JavaScript library used for building the user interface.
* [Udacity Books API](https://github.com/udacity/reactnd-project-myreads-starter) - The backend service providing book data.
